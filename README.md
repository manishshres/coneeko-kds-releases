# Coneeko KDS releases

Installers for the Coneeko kitchen display. Download `Coneeko-KDS-Setup.exe` from the [latest release](../../releases/latest).

Installed tills check this page and update themselves: they download the new installer, verify it against the `.sha256` file, and install it after hours when no tickets are open.

The source code is private; this repository holds only the built installers.
